消息呈现契约

后端只选意图
ANSWER
用户主动提问后的普通回答，不承诺方向导航，只展示 Agent 给出的结论与必要依据。
REMINDER
需要及时看到的重要提醒；使用感叹号，允许按策略播报。
TASK
明确任务或时间节点；使用任务图标，单击表示知道了。
CONSUMABLE
耗材余量建议；使用耗材图标，默认只显示文字。
PRIVACY
本地或云端策略状态；优先级最高，不能被普通 Agent 文案冒充。
  • 默认沉默：持续感知时不常驻文字，不占据视野。
  • 只有单绿：不使用灰、黄、红等颜色区分状态。
  • 最多两层：一个结论，加一行必要补充或一个动作。
  • 语义选组件：Agent 只返回呈现意图与文案，不能控制坐标、颜色、字号或动画。
  • 边框有含义：仅用细线、圆点和清晰的圆形状态图标。
  • Agent 是顾问：提供判断和建议，不扮演替用户做决定的管家。
  • 详情回手机：记忆列表、证据和设置在 RealGit 手机端查看。
