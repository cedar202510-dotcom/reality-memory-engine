这版的分类规则

领域回答“这段记忆属于生活的哪一部分”；物品、偏好和任务回答“在这个领域里记住了什么”。两者不再混为同一级分类。

购物不单独成为领域

买衣服进入穿搭，买食品进入饮食，买家居用品进入居住。采购只是一次行为，不是记忆最终归属。

任务、目标和进度统一为“计划”

任务是要做什么，目标是希望达到什么，进度是当前走到了哪里。它们共享同一条计划主线。

偏好和习惯附着在领域内

少糖是饮食偏好，喜欢宽松剪裁是穿搭偏好，晚上阅读是工作学习习惯，不再建立一个脱离生活的偏好仓库。
