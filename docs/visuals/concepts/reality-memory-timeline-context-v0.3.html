新的信息结构

首页不是关系网，也不是物品列表，而是一天的上下文时间轴。每一条不是原始事件，而是后端把证据、观察和候选聚合后形成的“人能读懂的一句话”。

第一层：时间轴今天做了什么、看到了什么、吃了什么、发生了什么重要变化。
第二层：片段详情展开这个片段里的物品、偏好、任务、空间、人际关系。
对象路径如果点击物品，就看这个物品在时间维度上的位置、数量、使用、归属变化。
关系视图用于服装搭配、常吃食物、人物任务、物品组合等长期关系。

哪些内容适合进入首页时间轴

首页应该克制，只放摘要性强、用户可能关心、可以被追问或纠正的片段。

活动片段出门、午餐、阅读、到家、洗衣、购物、工作会面。
状态变化物品移动、耗材下降、任务完成、阅读进度、偏好表达。
需要确认低置信偏好、疑似任务、归属不清的物品、冲突位置。
不放首页大量相似图片、传感器峰值、无信息增量的普通帧、模型中间输出。

关系网应该放在哪里

关系网适合做第二层：点击“午餐”看食物、店铺、评价、偏好；点击“服装”看衣服之间的搭配；点击“钥匙”看它和玄关、背包、出门的长期关系。这样它是解释上下文的工具，不是首页负担。
