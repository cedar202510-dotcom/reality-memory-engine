在场

你看到的现实，它也在理解。物品、行动和偏好会在需要时被唤起。

正在整理今天的现实上下文 没有重要变化时，它保持安静；你也可以直接问。

这版先解决三个问题。

中心不再放“在”这个字，避免像一句话或 Logo。页面标题保留“在场”，但下面立刻解释它的含义：你看到的现实，它也在理解。Agent 形象改成抽象的 presence glyph，像一个有观察能力的小小生命体，但不拟人。

交互排版要有意义。

底部不再出现“声”这种含义不清的文字，而是一个明确的麦克风形态。主按钮只承担一件事：按住说话。文字输入和“看看今天”是次级动作，不和语音入口抢位置。

标题“在场”可以作为产品气质，但必须配一句解释，否则用户不知道它是什么。
形象不放文字，不放头像，不做机器人。用光、环、核心和小亮点表达理解现实。
状态页面告诉用户它正在整理上下文，不夸张承诺“全知全能”。
动作主动作是语音，次动作是输入文字和查看今天，层级清楚。
