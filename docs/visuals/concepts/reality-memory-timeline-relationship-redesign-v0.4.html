这版时间轴的写法规则

之前奇怪的根源是：把模型状态写成用户内容。这版改成更自然的人话，并且承认不确定性。

不用工程标签不写候选、片段、聚合、实体。换成“待确认”“已记录”“要不要记住”。
不把推测写成事实确定的写确定，不确定的用问题形式交给用户确认。
每条都要有价值用户看完要知道为什么出现，以及下一步能做什么。
关系网在第二层首页讲今天发生什么；点开后才讲这件事牵出了哪些关系。
