v0.3 的问题

它像暗色控制台：标题太大、状态太硬、中心像雷达或监控镜头，底部按钮又像功能面板。整体在说“系统正在运行”，而不是“一个懂你的 Agent 在这里”。

v0.4 的修正

这版把“在场”降成轻量身份，主问题变成“想确认什么？”。中心形象不再像眼睛或雷达，而是一个柔和的存在。底部只保留语音主动作，次动作变成轻量文字入口。

品牌“在场”作为身份，不当巨型海报标题。
形象不用文字、不用眼睛，改成柔和的 seed / presence。
文案少说“正在整理上下文”，多说用户能做什么。
动作语音是主入口，文字和今天是低权重次入口。
