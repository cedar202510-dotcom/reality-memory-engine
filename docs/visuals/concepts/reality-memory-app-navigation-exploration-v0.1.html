Reality / 在场 · 无底部导航探索 v0.1

底部导航不是必须的。必须的是用户始终知道自己能问、能看、能控制。

这页不是最终视觉稿，而是三种交互形态探索：用 Agent 作为中心、用今天的流作为入口、用上拉控制面板替代固定 Tab。导航可以消失，但返回、控制和边界不能消失。

我的判断 真正的手机 App 可以不要传统底部 Tab，但第一版不能把入口藏得太深。更稳的方案是“Agent 首页 + 记忆星系 + 上拉控制”，视觉上没有固定导航，逻辑上仍有清楚层级。

A. Agent 中心宇宙

进入 App 后只有一个中心 Agent。物品、偏好、任务、耗材、设备像星体围绕它。用户不是点 Tab，而是点记忆领域或直接说话。

B. 今天流 + 命令入口

没有导航栏，首页是一条智能整理过的“今天”。所有主动提醒、候选确认和记忆摘要都在流里。底部只是语音命令，不是导航。

C. 单页主屏 + 上拉控制

首页保持非常干净，只有 Agent 和少量状态。需要查看记忆、设备、隐私时，从底部上拉面板进入。它是控制面板，不是常驻导航。
