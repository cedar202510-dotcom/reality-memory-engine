# PICO wardrobe assets

The eight PNG files in `items/` are project-local generated assets. Each image
contains one front-facing garment with an alpha channel and no background.

Generation brief:

- Photorealistic fashion product photography
- Front view, full garment visible
- No person, mannequin, hanger, logo, text, prop, or shadow
- Flat chroma-key source background removed locally after generation

The chroma-key source images are intentionally not included in the public asset
directory.
